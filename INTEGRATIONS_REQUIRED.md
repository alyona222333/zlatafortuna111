# Зовнішні інтеграції CRM

Цей файл містить лише назви потрібних доступів. Секретні значення API-ключів не потрібно зберігати в GitHub або в цьому файлі.

## Уже підключено

| Сервіс | Стан | Що перевірити |
|---|---|---|
| Telegram | Підключено | Webhook, команда `/start`, повідомлення власнику |
| Nova Poshta | Підключено частково | Пошук міст і відділень; для створення ТТН потрібні дані відправника |
| Supabase | Потрібен для роботи CRM | URL проєкту, anon key, service role key, database connection string |

## Потрібно для завершення Nova Poshta

1. API-ключ Nova Poshta.
2. Назва компанії-відправника.
3. Місто відправлення.
4. Відділення або адреса відправника.
5. Ім'я та телефон контактної особи.
6. Налаштування післяплати, якщо вона потрібна.

## Ukrposhta

Потрібно отримати:

1. Підписаний договір або доступ до кабінету відправника.
2. API token Ukrposhta.
3. Client ID або інший ідентифікатор, якщо його вимагає тариф.
4. Дані відправника.
5. Місто, індекс і адресу відправлення.
6. Налаштування післяплати та типу доставки.

## Телефонія

Спочатку потрібно вибрати одного провайдера. Не потрібно давати доступи від усіх одразу.

Можливі варіанти:

- Binotel;
- Ringostat;
- Zadarma;
- Twilio;
- Telnyx;
- SIP-провайдер із webhook API.

Після вибору потрібні:

1. API key або access token.
2. Account ID або project ID.
3. Номер телефону, який буде використовуватись CRM.
4. Webhook URL для вхідних дзвінків.
5. Webhook URL для статусів дзвінків.
6. Правила запису розмов, якщо запис потрібен.

## Email

Один із варіантів:

- SMTP host, port, username, password, sender email;
- Resend API key і підтверджений sender domain.

## SMS

Потрібно вибрати провайдера, наприклад TurboSMS, AlphaSMS, SMSClub або іншого українського постачальника.

Після вибору потрібні:

1. API key або login/password.
2. Sender name.
3. Webhook для статусів доставки, якщо підтримується.
4. Обмеження та тариф відправки.

## WhatsApp

Потрібні:

1. Meta Business account.
2. WhatsApp Business App.
3. Phone Number ID.
4. Permanent access token.
5. Business Account ID.
6. Підтверджений номер телефону.
7. Message templates, схвалені Meta.
8. Webhook verify token.

## Viber

Потрібні:

1. Viber bot або Public Account.
2. Auth token.
3. Публічна HTTPS-адреса CRM для webhook.

## WooCommerce та інші інтернет-магазини

Для WooCommerce:

1. URL магазину.
2. Consumer key.
3. Consumer secret.
3. Webhook secret.
4. Події замовлень, які треба передавати в CRM.

Для Rozetka або іншого маркетплейсу потрібні API-документація та ключ продавця.

## Що не потрібно надсилати в чат

Не надсилайте сюди:

- паролі від кабінетів;
- повні API-ключі у відкритому повідомленні;
- seed-фрази;
- банківські паролі;
- коди двофакторної автентифікації.

Ключі краще додавати в Netlify Environment Variables або вводити через захищену форму налаштувань CRM. У коді проєкту зберігаються тільки назви змінних середовища.
