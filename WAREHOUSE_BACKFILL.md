# Разовое заполнение склада

Один командой заполняет «Склад» товарами из вашей CSV-выгрузки сайта и
сразу сверяет их с четырьмя прайсами поставщиков по артикулу.

## Что нужно

Из Supabase → Project Settings → API:
- `NEXT_PUBLIC_SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY` (не анонимный ключ — именно service role)

## Запуск

```bash
npm install
NEXT_PUBLIC_SUPABASE_URL="https://xxxx.supabase.co" \
SUPABASE_SERVICE_ROLE_KEY="eyJ..." \
  npm run warehouse:backfill
```

По умолчанию скрипт берёт `data/site-export.csv` — это ваша выгрузка,
уже включённая в проект. Свой файл можно передать первым аргументом:

```bash
npm run warehouse:backfill -- path/to/другой-export.csv
```

## Что делает

1. Читает CSV, отбрасывает вариации и неопубликованные товары, заносит
   остальное на склад (source = site).
2. Добавляет четыре прайса поставщиков (Urban Shop, Rimari, LuxyArt,
   Domino opt) — если уже добавлены, пропускает.
3. Скачивает все прайсы, сводит по артикулу, проставляет наличие и
   закупочную цену.

В конце печатает отчёт: сколько товаров, сколько сведено, сколько в
наличии. Скрипт идемпотентный — можно запускать повторно, дубликатов не
будет.

Дальше «Оновити всі» на странице «Постачальники» делает то же самое —
можно продолжать нажимать кнопку в интерфейсе, скрипт нужен один раз
для первого запуска.

## Автообновление по расписанию

`/api/cron/warehouse-sync?secret=ВАШ_CRON_SECRET` обновляет наявність
автоматически, без участия человека. Обработчик заточен под тот же
лимит хостинга: за один вызов он делает только один маленький шаг —
скачивает один просроченный прайс или один раз сверяет склад — и
выходит. Значения `secret` берётся из переменной окружения `CRON_SECRET`.

Поэтому внешний планировщик (например, [cron-job.org](https://cron-job.org))
нужно настроить на **частый** вызов — раз в 3–5 минут, а не раз в час.
Сама частота обновления наявності регулируется не этим интервалом, а
полем `auto_sync_minutes` в настройках склада (по умолчанию 60 минут) —
достаточно нескольких быстрых тиков подряд, чтобы пройти все прайсы и
свести их со складом, не упираясь в таймаут ни на одном шаге.
